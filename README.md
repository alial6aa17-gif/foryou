# FOR YOU — متجر هدايا وتوزيعات عراقي

نظام أولي متكامل يعمل بـ Node.js native فقط، دون npm dependencies. واجهة عربية RTL وMobile-first، مع متجر عام ولوحة دخول ولوحة إدارة حسب الدور.

## التشغيل

- يتطلب Node.js 18+ (يوصى Node 20 أو 22).
- لا يحتاج `npm install`.
- شغّل: `node server.js`
- افتح: `http://localhost:3000`

## حساب المدير الأولي

- اسم المستخدم: `owner`
- كلمة المرور: `ChangeMe-Now-123!`

**غيّر كلمة المرور قبل نشر النظام.** الحساب الأولي موسوم بتحذير أمني في واجهة الدخول واللوحة. هذه النسخة توفر إضافة موظفين بكلمات مرور scrypt، لكنها لا تتضمن واجهة تغيير كلمة مرور للمالك؛ لذلك لا تنشرها مباشرة قبل إضافة تغيير كلمة المرور أو تعديل seed آمن.

## Railway / Volume

1. أنشئ خدمة Node.js من المستودع.
2. أضف Volume، مثلاً `/data`.
3. عيّن متغير `DATA_DIR=/data`.
4. عيّن `PORT` إن لم تستخدم المنفذ الافتراضي.
5. ارفع ملفات المشروع إلى الجذر وشغّل `node server.js`.

كل JSON يكتب إلى ملف مؤقت ثم `rename` ذري داخل DATA_DIR. الصور تحفظ في `DATA_DIR/uploads`. احرص على أن يكون Volume دائم ومتاحاً للكتابة.

## الملفات

- `server.js`: HTTP server، JSON store، sessions، scrypt، rate limiting، API.
- `index.html`: المتجر العام، الأقسام، السلة، التتبع، حاسبة آسيا.
- `login.html`: تسجيل دخول الموظفين.
- `dashboard.html`: لوحة الإدارة والمبيعات والمخزن والتجهيز.
- `README.md`: دليل التشغيل.

## الأدوار

- `owner`: إدارة المنتجات والإعدادات والمخزن والموظفين والمصاريف والتقارير.
- `admin`: إدارة الطلبات وتحديث الحالات.
- `sales`: إدخال طلبات إنستغرام.
- `prep`: تحديث حالة الطلبات وطباعة وصل الشحن.

## API مختصر

- `GET /api/store` المتجر العام.
- `POST /api/order` إنشاء طلب من السلة العامة.
- `GET /api/track?code=...` تتبع كود الطلب.
- `POST /api/login`, `POST /api/logout`, `GET /api/me`
- `GET /api/dashboard`, `GET /api/orders`, `GET /api/products`
- `POST /api/products`, `/api/order/admin`, `/api/order/status`
- `POST /api/settings`, `/api/expense`, `/api/employee`, `/api/stock`, `/api/upload`

## ملاحظات مهمة قبل الاستخدام التجاري

هذا تنفيذ MVP قابل للتشغيل وليس تدقيقاً أمنياً أو محاسبياً. يلزم قبل الإنتاج:
- إضافة تغيير كلمة المرور/إعادة تعيينها، وتدوير الجلسات، وCSRF token لعمليات POST، وHTTPS عبر المنصة.
- تحديد صلاحيات أدق لكل endpoint؛ حالياً صفحة لوحة العمل موحدة، بينما API يفرض الدور على الإجراءات الحساسة.
- إضافة خصم/إرجاع مخزون بمعاملات آمنة، سجل تدقيق، backup، واختبارات ضغط.
- إعداد ضريبة/رسوم/عمولة واضحة، واحتساب إلغاء الطلب وإعادة المخزون.
- حماية الصور من الملفات الضارة، وفحص MIME الفعلي، وحدود رفع، ونسخ احتياطي.
- واجهة تغيير كلمة المرور للمالك وإزالة كلمة المرور الافتراضية من المصدر.
- لا يوجد ربط مباشر أو إرسال آلي إلى Instagram/WhatsApp؛ النظام ينسخ النص ويتيح فتح Instagram لأن ذلك يحتاج صلاحيات/API رسمية.
- بيانات الدفع ZainCash/Mastercard إعدادات عرض فقط؛ لا يتم تخزين بيانات بطاقات ولا تنفيذ تحصيل إلكتروني.
- حاسبة آسيا تستخدم المعادلة المطلوبة: المبلغ ÷ 0.9.

## ملاحظة تشغيلية

إذا كانت بيانات JSON تالفة، لا يقوم النظام باستعادة تلقائية من نسخة احتياطية. احتفظ بنسخ من `DATA_DIR` بانتظام. لا تستخدم هذا MVP لمعالجة بيانات دفع حساسة.
